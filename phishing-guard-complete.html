Conseils de sécurité

Protégez vos codes PIN

Ne partagez jamais votre code PIN Mobile Money, Orange Money ou MTN MoMo avec personne, même si la personne se présente comme un agent du service client.

Codes OTP et validation

Ne communiquez jamais un code OTP (One-Time Password) ou un code de validation à quelqu'un qui vous contacte. Ces codes servent uniquement à vos propres transactions.

Vérifiez les notifications

En cas de doute sur une transaction, vérifiez directement dans votre application Mobile Money ou contactez le service client via les numéros officiels (ex: 150 pour MTN, 100 pour Orange).

Méfiez-vous des captures d'écran

Une capture d'écran de paiement peut être falsifiée. Vérifiez toujours que vous avez bien reçu l'argent sur votre compte avant de livrer un bien ou un service.

Offres d'emploi suspectes

Méfiez-vous des offres d'emploi qui demandent des frais de dossier ou des paiements avant l'embauche. Les entreprises sérieuses ne demandent jamais d'argent pour recruter.

Gains inattendus

Si on vous annonce un gain, un remboursement ou une aide financière inattendue, soyez très prudent. Vérifiez toujours auprès de l'organisme officiel concerné.

Ne cliquez pas précipitamment

Prenez le temps de vérifier les liens avant de cliquer. Survolez le lien avec votre souris pour voir l'adresse réelle. Les arnaques utilisent souvent l'urgence pour vous faire agir rapidement.

Vérifiez les coordonnées officielles

Avant d'effectuer un paiement, vérifiez les coordonnées officielles sur le site web de l'entreprise ou de l'organisation. N'utilisez jamais les numéros fournis dans un message suspect.
